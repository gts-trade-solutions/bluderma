# Brand assets

The production BluDerma identity is an original vector system:

- `logo.svg` is the portable horizontal logo.
- `src/components/BrandLogo.tsx` renders the responsive light/dark website version.
- `src/app/icon.svg` is the matching browser and app icon.

The nested-D monogram represents dermal layers, while the blue and teal palette
connects clinical trust with skincare. The legacy `logo.png` is retained only
as an archived source and is no longer rendered by the application.
